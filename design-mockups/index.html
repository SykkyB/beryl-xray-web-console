Design mockups

Three layouts for the xray-panel-cli rework — pick one, we apply it for real.

v1 · Stacked actions, prominent bind

Two equal columns; killswitch is a slim row below.
  • Buttons stacked vertically (left)
  • Big bind-toggle (right)
  • Killswitch as a thin divider row
  • Calmest, most "mobile-shaped"

v2 · Compact horizontal, inline killswitch

Wide-left action row, small bind aside; killswitch as inline strip.
  • Action buttons in a single row (compact)
  • Bind toggle as a slim sidebar block
  • Killswitch stripe with label + state + toggle
  • Tightest vertically

v3 · Hero status, 3-column controls

Big status strip up top, then Actions / Bind / Killswitch as equals.
  • Hero status row inside the card body
  • Three equal columns: actions, bind, killswitch
  • Active profile pill in hero (not header)
  • Most "dashboard"-looking

All three share the same Profiles card (Exit IP in header, Activate also starts the service when Auto-follow is OFF), the same Tabs structure (Control / Monitor), and the same palette. Differences are limited to the Sing-box card layout. Open each in a new tab to flip side-by-side.
