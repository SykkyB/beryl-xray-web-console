Manual control

Start, stop, or hot-reload the sing-box VPN client. Reload validates the config and re-applies it without losing the tunnel for long.

Bind

When on, sing-box follows the GL.iNet hardware mode switch on the side of the router (ON = start, OFF = stop). Acts like the native WG / OVPN binding.

Killswitch
… — when the tunnel goes down, LAN traffic is blackholed instead of falling back to the direct WAN. Off by default — same behavior as GL.iNet's stock WG / OVPN clients.
